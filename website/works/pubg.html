① 项目背景

玩家分层是游戏运营的核心动作。本作品用 PUBG 玩家对局行为数据,回答三个运营问题:

  • 谁是我们的高价值玩家? —— 建立玩家价值分层模型
  • 他们的行为特征是什么? —— 找出区分层的关键行为指标
  • 如何识别和培养? —— 输出可落地的运营方案

② 数据与方法

数据源:Kaggle PUBG 官方比赛数据,444 万条玩家对局行为记录,29 个字段。

聚焦策略:全量清洗后聚焦 四排第一人称(占全量 39.8%,最主流模式,最有代表性)。

分析维度使用的关键字段业务含义
战斗能力造成伤害 / 击杀数玩家"投入"与"潜力"
生存能力完赛名次 / 步行距离玩家"存活"与"留存"
资源行为捡武器数 / 能量道具玩家的"成长空间"

③ 关键发现:击杀数的"幂律分布"

玩家击杀数呈典型的 长尾分布 —— 56.8% 的玩家一局 0 击杀,极少数高手贡献绝大部分击杀。

运营洞察
  • 多数玩家不是高手 —— 运营要服务的重点,是占 56.8% 的"0 击杀"群体,而非少数高手
  • 击杀数是"结果",不能只看它 —— 用"伤害"更能提前发现"有投入但没结果"的潜力玩家

④ 玩家价值分层模型

用 战斗维度(造成伤害) × 生存维度(完赛名次) 交叉,建立 5 类玩家分层。为什么用"伤害"而非"击杀"?——击杀是结果,伤害是投入,用投入更能提前识别"有潜力但没结果"的玩家。

玩家分层占比画像
核心高手(全能)17.9%高伤害 + 高存活,顶尖玩家
潜力型(成长中)57.1%中坚主体,有成长空间
战斗型(有天赋但存活差)3.6%高伤害但存活差,有潜力但莽
生存型(苟活无输出)6.8%在线久但无输出,苟活玩家
双弱型(流失风险)14.6%0伤害 + 存活差,最需挽留
# 玩家价值分层:战斗维度(伤害) × 生存维度(名次)
# 用"伤害"而非"击杀",因为伤害是投入,更能提前识别有潜力但没结果的人
高伤害 = 四排['造成伤害'] >= 四排['造成伤害'].quantile(0.75)
零伤害 = 四排['造成伤害'] == 0
高名次 = 四排['完赛名次'] >= 0.5
低名次 = 四排['完赛名次'] < 0.3

四排['最终分层'] = '潜力型(成长中)'
四排.loc[高伤害 & 高名次, '最终分层'] = '核心高手(全能)'
四排.loc[高伤害 & 低名次, '最终分层'] = '战斗型(有天赋但存活差)'
四排.loc[零伤害 & 高名次, '最终分层'] = '生存型(苟活无输出)'
四排.loc[零伤害 & 低名次, '最终分层'] = '双弱型(流失风险)'

print(四排['最终分层'].value_counts(normalize=True).round(3))

⑥ 深度洞察:"落地成盒"的流失风险群体

审计发现 5.9% 的玩家完赛名次 = 0。这不是异常数据,而是真实的"落地成盒"信号:

指标数值解读
平均步行距离45 米开局落地后几乎没动就死了
平均对局时长1560 秒整局26分钟,但他们只活了最初1分钟
平均击杀0.1连枪都没摸到
运营洞察

这批玩家游戏体验极差(落地秒死、无正反馈),是最容易流失的群体。他们是"双弱型"的极端代表,运营应重点介入。

# 数据审计:名次=0 是异常数据还是真实信号?

⑦ 运营落地方案

基于数据洞察,为每类玩家设计差异化的运营策略。

双弱型(流失风险)14.6% —— 新手保护
  • 新手保护匹配:前几局安排 AI/人机,给首次击杀的正反馈
  • 落地引导:新手教学提示跳野外人少区域,避免热门点被秒
  • 战斗教学:靶场/训练场,建立战斗自信
  • 匹配优化:让落地成盒玩家匹配水平相近者
生存型(苟活无输出)6.8% —— 激励参与战斗
  • 战斗任务激励:战斗任务、伤害成就奖励
  • 伤害统计展示:让玩家看到自己的战斗贡献
  • 资源收集引导:把"苟"转化为"积累"的成就感
战斗型(有天赋但存活差)3.6% —— 潜力引导
  • 跑圈教学:提示占点时机、毒圈推进节奏
  • 生存技巧引导:让战斗天赋转化为名次
  • 潜力识别:标记为"高潜力玩家"重点培养
潜力型(成长中)57.1% —— 保持活跃
  • 常规活跃活动:保持在线粘性
  • 成长激励:段位晋升、累计击杀里程碑
核心高手(全能)17.9% —— 竞技与内容
  • 竞技激励:段位/天梯、大神身份标识
  • 内容产出:邀请做教学/直播/攻略
  • 社区 KOL 培养
